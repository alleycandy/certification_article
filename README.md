aws article
I checked the official AWS Student Rewards announcement and the current AWS Builder Center guidance. AWS confirms that badges are earned through actions such as completing your profile, publishing articles, commenting, maintaining engagement, creating Wishes, and voting on Wishes. 7 badges unlock $10 AWS Credits, 14 badges unlock another $20, and 21 badges unlock a $100 AWS Foundational Certification exam voucher.
Below is the shortest practical roadmap I recommend.
🔗 Start Here
→ AWS Builder Center
→ Student Rewards announcement
→ Builder Center Guide
🟢 PHASE 1 — Get the Easy Badges First
Goal: 6 badges as quickly as possible
1. Knowledge Seeker
→ Open Builder Center
→ Sign in
→ Explore/read Builder Center content
→ 🏆 Knowledge Seeker
2. Hello, World!
→ Complete your Builder profile
→ Finish the required onboarding/profile steps
→ 🏆 Hello, World!
3. Photo Finisher
→ Open your Builder Center profile
→ Add a profile photo
→ Save
→ 🏆 Photo Finisher
4. Discussion Debut
→ Explore Builder Center
→ Join a relevant Space
→ Create your first discussion/post
→ 🏆 Discussion Debut
5. First Wish
→ Open Wishlist
→ + → Create Wish
→ Write a useful AWS feature idea
→ Submit
→ 🏆 First Wish
AWS specifically recommends checking existing Wishes first and commenting on an existing one instead of creating a duplicate.
6. First Article
→ Open Builder Center
→ + → Create Article
→ Write your first article
→ Preview → Publish
→ 🏆 First Article
AWS's official Builder Center guide confirms the + → Create article → Preview → Publish flow.
🎯 Result
6 / 21 badges
🟡 PHASE 2 — Start All 7-Day Streaks
Do NOT wait until Phase 1 is finished. Start these on Day 1.
7. 7-Day Sign-In Streak
→ Sign in to AWS Builder Center
→ Repeat every day
→ 7 consecutive days
→ 🏆 7-Day Sign-In Streak
8. 7-Day Like Streak
→ Sign in
→ Read content
→ Like relevant content
→ Repeat for 7 days
→ 🏆 7-Day Like Streak
9. 7-Day Comment Streak
→ Sign in
→ Read an article/discussion
→ Leave a meaningful comment
→ Repeat for 7 days
→ 🏆 7-Day Comment Streak
Current Builder Center profiles confirm these 7-day streak badges are actively being awarded.
🎯 Result
9 / 21 badges
🟠 PHASE 3 — Run the 4-Week Streaks in Parallel
Start these from Day 1.
10. 4-Week Wish Vote Streak
→ Open Builder Center

→ Vote on relevant Wishes
→ Repeat every week
→ 4 weeks
→ 🏆 4-Week Wish Vote Streak
11. 4-Week Article Publishing Streak
→ Week 1 → Publish Article #1
→ Week 2 → Publish Article #2
→ Week 3 → Publish Article #3
→ Week 4 → Publish Article #4
→ 🏆 4-Week Article Publishing Streak
Current Builder Center profiles show both of these 4-week badges being awarded.
🎯 Result
11 / 21 badges
🟠 PHASE 4 — Continue to 30 Days
Don't restart anything. Continue the same daily habits.
12. 30-Day Sign-In Streak
→ Sign in every day
→ Day 1 → Day 30
→ 🏆 30-Day Sign-In Streak
13. 30-Day Like Streak
→ Sign in
→ Like relevant content
→ Day 1 → Day 30
→ 🏆 30-Day Like Streak
14. 30-Day Comment Streak
→ Sign in
→ Leave a meaningful comment
→ Day 1 → Day 30
→ 🏆 30-Day Comment Streak
Current Builder profiles demonstrate the 30-day visit/comment/like badges in the program.
🎯 Result
14 / 21 badges
🎁 $10 AWS Credits at 7 badges + another $20 at 14 badges.
